# 🎁 交換禮物網站

GitHub Pages（前端）＋ Google Sheet（資料儲存，透過 Apps Script 當 API）。

| 頁面 | 用途 |
|---|---|
| `index.html` | 填寫頁（QR code 指向這裡）：姓名＋三個禮物特徵，勾選哪一個是假的 |
| `display.html` | 大螢幕：全部顯示 / 動態展示，右下角有 QR code，管理者按「公佈」時跳出揭曉動畫，開票時播放頒獎典禮 |
| `vote.html` | 投票頁（投票期間大螢幕的 QR code 會指向這裡）：三個獎項各選 1～3 份禮物 |
| `admin.html` | 管理後台（需密碼）：看所有答案、公佈、刪除、全部重置、切換大螢幕顯示模式與速度、管理投票與開票 |

---

## 架設步驟

### 1. 建立 Google Sheet 與 Apps Script
1. 到 Google 雲端硬碟新增一個 Google 試算表（名稱隨意，例如「交換禮物」）。
2. 上方選單「擴充功能 → Apps Script」。
3. 把 `apps-script/Code.gs` 的內容整份貼上，取代原本的程式碼，存檔。
4. 左側「⚙ 專案設定」→ 最下方「指令碼屬性」→ 新增屬性：
   - 屬性：`ADMIN_PASSWORD`
   - 值：你的後台密碼
5. 回到編輯器，上方函式選單選 `setup` → 按「執行」，依提示授權（會出現「Google 尚未驗證這個應用程式」→ 進階 → 前往（不安全）→ 允許，這是你自己的程式所以沒關係）。
   試算表中會出現 `Gifts`、`State`、`Votes` 三個分頁。

### 2. 部署成網頁應用程式
1. 右上角「部署 → 新增部署作業」→ 齒輪選「網頁應用程式」。
2. 執行身分：**我**；存取權：**所有人**。
3. 按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。

> ⚠ 之後如果修改了 Code.gs，要用「部署 → 管理部署作業 → 編輯（鉛筆）→ 版本：新版本」重新部署，網址才會維持不變。

### 3. 設定前端
打開 `assets/config.js`，把 `API_URL` 換成上一步的網址。

### 4. 發佈到 GitHub Pages
1. 在 GitHub 建一個 repository，把這個資料夾的檔案推上去。
2. Repository → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main` / `(root)` → Save。
3. 約一分鐘後網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

## 當天使用方式

1. 投影電腦開 `https://…/display.html`，按「全螢幕」。
   - 右下角就是填寫頁的 QR code，點一下可以放大，再點一下隱藏。
2. 大家掃 QR code 填寫，大螢幕每 3 秒自動更新。
3. 主持人用手機開 `https://…/admin.html` 登入。
   - 最上方「大螢幕顯示」可以切換**全部顯示／動態展示**、調整動態展示的**速度**，大螢幕約 3 秒內跟著變。
4. 某份禮物被選走後，在後台按該筆的「公佈」→ 大螢幕跳出動畫：假的詞被打叉，並揭曉是誰的禮物。
   公佈過的禮物在大螢幕上會**變灰並蓋上「已送出」印章**，表示不能再選。
5. 交換完畢後進行投票（見下方）。
6. 活動結束（或測試完）按「全部重置」清空資料（禮物與投票都會清掉）。

### 投票與開票
1. 開場時先在大螢幕上按一下工具列的「🔇 音效」，變成「🔊 音效」才會有開票音效（瀏覽器規定網頁要先被點過才能出聲；之後重新整理頁面，只要再點畫面任何地方一下就會恢復）。
2. 後台「🗳️ 投票」面板按「開始投票」→ 大螢幕右下角 QR code 換成投票頁，文字變成「掃我投票」。
3. 大家掃碼投票：填名字，三個獎項（🎁 最驚喜、😂 最搞笑、💝 最想收到）**每項選 1～3 份不同的禮物**，每份各得 1 票，可以投自己的禮物。
   - 同一個名字（忽略大小寫與空白）再送出一次會**覆蓋舊票**，所以投票結束前都可以改。
4. 後台即時看到每個獎項的票數長條和投票名單（「投票名單」展開可看誰投了什麼）。
5. 按某個獎項的「🏆 開票」→ 大螢幕播放頒獎典禮：鼓聲＋聚光燈 → 頒獎台升起 → 第 3 名 → 第 2 名 → 鼓聲 → 第 1 名＋號角＋彩帶。
   - 開票時如果投票還開著，會先自動結束投票。
   - 同票會**並列同一名次**（例如兩個第 2 名就沒有第 3 名）。
   - 播完停在結果畫面方便拍照，點一下或按 `Esc` 關閉。已開過的獎項可按「🔁 重新開票」再播一次。
6. 想重來可以按「清空投票」（輸入 CLEAR 確認），手機上記住的投票也會一起作廢。

### 大螢幕顯示模式（在管理後台切換）
- **全部顯示**：所有禮物排成格狀，自動依螢幕大小與份數調整欄數和字級。
- **動態展示**：禮物排成 2～3 列跑馬燈緩緩流動，背景飄雪。
  移動速度在後台調整（1 最慢、10 最快，預設 3），變速時會從目前位置接續、不會跳動。
  剛送出的禮物會在牆上發金光並標示「NEW」約 90 秒。
  主持人按 ← → 可以把某份禮物放大到中央，停留幾秒後自動收起（秒數在 `assets/config.js` 的 `CAROUSEL_SEC`）。
- **新禮物飛入**（兩種模式都有）：有人送出時，卡片從 QR code 飛出、在中央放大停留一下，
  再飛進牆上讓出的空位；同時多份會依序一份一份飛入。

### 大螢幕快捷鍵
| 鍵 | 功能 |
|---|---|
| `A` | 臨時切到全部顯示（後台下次改設定時會以後台為準） |
| `C` | 臨時切到動態展示（← → 放大上一份／下一份禮物） |
| `Q` | QR code：小 → 大 → 隱藏 |
| `F` | 全螢幕 |
| `H` | 隱藏工具列（滑鼠移上去會出現） |
| `Esc` / 點一下 | 關閉公佈動畫或開票畫面 |

## 本機測試
```bash
npx serve .
```
開 `http://localhost:3000/index.html`、`display.html`、`admin.html`（需先完成步驟 1～3）。

## 說明
- 送出時伺服器會把三個詞隨機打亂順序，所以假的不會固定在同一個位置。
- 公開 API 不會回傳未公佈禮物的姓名與假詞，只有後台（需密碼）看得到。
  例外：**投票開放期間**，投票頁會列出所有禮物的送禮者和假詞（投票時大家需要知道是誰的禮物）。
- 開票結果在按下「開票」當下存成快照，之後就算有人再投票也不會改變已公布的名次。
